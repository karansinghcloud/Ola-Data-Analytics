# 📌 Project Overview

A large-scale synthetic Ola ride-booking dataset designed for real-world data analytics, SQL practice, Power BI dashboards, and business intelligence reporting.

The project simulates ride operations across Bengaluru for October 2025 and demonstrates end-to-end data analysis from raw transactional data to executive dashboards.

---

# 🎯 Business Objective

The goal of this project is to help stakeholders monitor and improve:

* Ride Success Rate
* Customer & Driver Cancellations
* Revenue Performance
* Payment Trends
* Customer Satisfaction
* Driver Performance
* Booking Patterns
* Operational Efficiency

# 🔍 Business Rules Applied

The dataset follows realistic operational constraints:

✅ Ride Success Rate: 62%

✅ Customer Cancellation: ≤ 7%

✅ Driver Cancellation: ≤ 18%

✅ Incomplete Rides: < 6%

✅ Weekend Demand Surge

✅ Match Day Booking Spike

✅ Booking ID Format:

```
CNR##########
```

✅ Booking Value Distribution

* Under ₹500 → 70%
* ₹501–₹1000 → 28%
* Above ₹1000 → 2%
